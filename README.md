# LPガス容器設計

1件あたりのガス消費量・建物全体の件数・同時使用率から1時間あたりの必要ガス量を算出し、
それをまかなえるLPガス容器の大きさと本数を求めるブラウザアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

1. 設計条件を入力する（1件あたりのガス消費量 m³/h、件数、同時使用率 %、予備側の有無）
2. 「係数設定」で換算係数と容器1本あたりのガス発生能力を設計基準の値に置き換える
3. 容器サイズ別の必要本数と推奨構成を確認する

## 計算方法

| 手順 | 式 |
| --- | --- |
| 最大ガス消費量 | `Q_max = 1件あたりの消費量 [m³/h] × 件数` |
| 必要ガス量 | `Q = Q_max × 同時使用率 / 100` |
| 質量換算 | `W [kg/h] = Q × 換算係数 [kg/m³]` |
| 使用側本数 | `N = ceil(W / 1本あたりのガス発生能力 [kg/h])`（最低1本） |
| 設置本数 | 予備側あり `N × 2`、予備側なし `N` |

推奨構成は設置本数が最少の容器（同数なら供給能力の余裕が小さい方）です。

## 係数について（要確認）

以下は参考資料で確認できていない **暫定値** です。画面上で変更できます。

| 係数 | 暫定値 |
| --- | --- |
| 換算係数 | 2.0 kg/m³（1kg ≒ 0.5m³） |
| 10kg容器のガス発生能力 | 0.3 kg/h |
| 20kg容器のガス発生能力 | 0.55 kg/h |
| 30kg容器のガス発生能力 | 0.7 kg/h |
| 50kg容器のガス発生能力 | 1.0 kg/h |

確定値が決まったら `calc.js` の `DEFAULT_COEFFICIENTS` を更新してください。
