# LPガス容器設計

1件あたりのガス消費量・建物全体の件数・同時使用率から1時間あたりの必要ガス量を算出し、
参考資料「第4章 容器本数の決定及び貯蔵設備の位置・広さ」の標準のガス発生能力表と算定式にもとづいて
LPガス容器（自然気化方式）の大きさと設置本数を求めるブラウザアプリです。

## 公開URL

https://iidas-m.github.io/LPG-design/

- パソコン・スマートフォンのブラウザでそのまま使えます
- 一度開けばオフラインでも動きます
- ホーム画面に追加（Chrome: メニュー →「アプリをインストール」、iPhone Safari: 共有 →「ホーム画面に追加」）するとアプリとして起動できます
- `index.html` をブラウザで直接開いても動きます（この場合オフライン機能は無効）

## デプロイ

`.github/workflows/pages.yml` が push のたびにテストを実行し、GitHub Pages に公開します。
初回のみ、リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」にしてください。
アプリのファイルを変更したら `sw.js` の `CACHE` の版数を上げてください。

## 使い方

1. 用途（一般住宅／業務用）、1件あたりのガス消費量（m³/h または kW）、件数、同時使用率を入力する
2. 供給方式は件数から自動判定（1件: 戸別、2〜10件: 小規模集団、11〜69件: 中規模集団）
3. 調整器、供給ガス、ピーク時の気温、ピーク時間を選ぶ
4. 設置場所の制限で使える容器が限られる場合は「容器サイズ（設置場所の制限）」で指定する（既定は自動選定）
5. 容器サイズ別の設置本数と推奨構成、自動切替式調整器の能力、容器交換周期の目安を確認する（1件あたり1か月の消費量は m³/月 が既定、kg/月 も選択可）

## 計算方法（参考資料 4.2）

| 供給方式 | 算定式 |
| --- | --- |
| 戸別・業務用 | `N = Q / (V × 14)` |
| 小規模集団 1系列 | `N = Q × 1.1 / (V × 14)` |
| 小・中規模集団 2系列 | `N = Q × 0.7 × 1.1 / (V × 14)` |

- `Q`: 最大ガス消費量 [kW] = 1件あたりの消費量 × 件数 × 同時使用率
- `V`: 標準のガス発生能力 [kg/h・本]（表Ⅱ－4－1、表Ⅱ－4－2、寒冷地・短時間消費の参考表）
- 集中監視システムで残量管理する場合は安全率 1.1 を 1.0 にできる
- 使用側本数は切り上げ（最低1本）。自動切替式調整器では予備側を考慮して2倍
- 自動切替式調整器の能力 = `Q × 1.0 / 14` [kg/h] 以上

算定例（戸別 59.7kW → 2本、小規模集団 109.0kW → 4本、中規模集団 377.5kW → 18本、69戸設計例 → 18本）を
`test/calc.test.js` で再現しています。

## ガス発生能力の決め方

1. 設計基準の表（表Ⅱ－4－1、表Ⅱ－4－2、寒冷地・短時間消費の参考表）の値
2. 設計基準に値がない条件は、追加資料「LPガス 発生能力早見表」の値で補う
   （プロパン・い号、残液約30%の目安値。い号ガス PP95%以上にのみ適用。1時間ピークの幅は下限値を採用）
3. それでも値がない条件は、安全側（発生能力が小さい側）の値で代用（画面では ※ 印）
   - 早見表のより長いピーク時間（連続使用の値は短いピークにも安全側）
   - 設計基準の単段調整器の表 → より低い規格のガス → より長いピーク時間
4. 30kg容器は資料に値がないため、20kg容器の値（1〜3 の順）で代用

推奨構成は設計基準の値がある容器を優先して選びます。
自動切替式調整器では 50・30・20kg容器、単段調整器では 50・30・20・10kg容器を表示します。
バルク貯槽は対象外です。

## 係数

| 係数 | 値 | 備考 |
| --- | --- | --- |
| LPガスの換算 | 1m³/h ＝ 2kg/h | 既定値。画面の「係数設定」で変更可。m³/h・m³/月 入力時に使用（1m³ ＝ 2kg） |
| kg/h → kW | 14 kW | 参考資料の算定式による |

## 対象外

強制気化方式、70戸以上（ガス事業法）、は号ガス。
